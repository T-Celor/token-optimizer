# Claude Stack

- To start Claude Code through the stack, run `%USERPROFILE%\.token-stack\bin\claude-stack.cmd`.
- To check status, read `%USERPROFILE%\.token-stack\gate-events.jsonl`.
- Never print secrets, API keys or tokens from the stack's configuration or logs.
